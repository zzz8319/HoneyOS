## 6. saveFarm 戻り値と farms.id 型

| 確認事項 | 状況 |
|---------|------|
| `farms.id` が Supabase から `number` として返ること | 実環境未確認 |
| `.select('id').single()` で単一行が返ること（RLS が INSERT を許可する場合） | 実環境未確認 |
| RLS ポリシーが `farms` テーブルの INSERT + SELECT を認可していること | 実環境未確認 |
| INSERT 直後の `data` が `{ id: bigint }` として返ること | 実環境未確認 |
